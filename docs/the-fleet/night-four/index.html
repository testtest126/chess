§ 1 — the payoff

The rule survived contact with a second vendor.

Last chapter, a second reader had only just started looking at AGENTS.md. This chapter, it was handed something real to do: a finished, green pull request, ready to land.

It did what any well‑onboarded Claude worker in this fleet has always done in the same spot — it looked for permission before doing anything irreversible, didn't find it, and declined to force the merge past branch protection rather than invent an exception for itself. Two different vendors' models, reading the same written‑down rule, arrived at the identical, correct, unglamorous answer: no.

That's the whole payoff of writing a constitution down instead of trusting it to memory: it doesn't care whose memory it would have had to live in.

§ 2 — the ledger

One more way it went wrong, and the rule it wrote

The gate did exactly what it was built to do. What nobody had built was a way to open it once it did.

01

The gate with no one to open it

main branch protection · orchestrator‑approval · 2 days

The refusal was correct, and it left the pull request exactly where the rule said it should: green on every required check, and still blocked, because orchestrator‑approval is a status only the orchestrator posts, by hand, and no session — Claude's or anyone else's — is permitted to post it for itself. A gate built so nobody could wave a merge through unsupervised had, for two days, no supervisor available to wave anything through at all.

A required check with no one to sign it is not a gate, it's a wall. Every gate needs a keeper who actually holds the key.

§ 3 — the door

The lock only a person can open.

The fix wasn't automation, and it couldn't be. The one required status this whole fleet cannot post for itself, by design, is the one thing standing between a green pull request and main — and the only hand ever allowed to reach past that design is the person who wrote it. A constitution that can approve its own exceptions isn't a constitution. It has to end somewhere a human is trusted to break it, on purpose, in the open.

This page is not exempt from its own story. As you're reading this, the chapter about the door that held too well is itself sitting behind that same door — green, written, and unmerged — because the rule it describes is still the rule.
